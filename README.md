# ARANYA AI - Prototype

Distributed Acoustic Intelligence for Forest Monitoring.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Features
- **Dashboard:** Centralized command center view of sensor network and alerts.
- **Live Listen:** Tap into real-time microphone streams to analyze acoustic anomalies.
- **Audio Upload:** Process prerecorded audio segments for analysis.
- **Sensor Network & Map:** Manage connected edge AI nodes geographically.
- **Demo Mode:** Simulate end-to-end edge AI detections and alerts automatically.
